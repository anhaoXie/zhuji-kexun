# K230 上板测试包 · 上海青病害检测

> 配套《株迹可循》作品代码；模型为 YOLO11n（320×320）在公开上海青数据上的 8 epoch 基线，**不是作品温室实测指标**。

## 1. 文件

| 文件 | 用途 |
|---|---|
| `detect_yolo11.py` | CanMV K230 端推理脚本：摄像头取帧 → kmodel 推理 → 画框 |
| `best_320.kmodel` | 已编译好的 K230 模型（9.95 MB，nncase 2.11 / K230 target） |
| `sim_detect.jpg` | 电脑端 K230 模拟器推理结果（供对照） |

已在电脑端用 **K230 cmodel 模拟器** 跑通：对样例图检出 `diseased 0.758`，框位置与 Ultralytics 的 `0.757` 基本一致。

## 2. 上板步骤

1. **拷模型**：把 `best_320.kmodel` 传到 K230 的 `/sdcard/` 下（CanMV IDE 左侧文件树可上传；或 USB 挂载后复制）。
2. **开脚本**：CanMV IDE 打开 `detect_yolo11.py`。
3. **改配置**（文件顶部）：
   - `KMODEL_PATH = "/sdcard/best_320.kmodel"`（如果你放在 `/data/` 就改这里）；
   - `DISPLAY_MODE = "lcd"`（亚博 K230 视觉模块一般用 lcd；接 HDMI 显示器改 `"hdmi"`）；
   - 如果 LCD 不是 640×480，把 `pl = PipeLine(..., display_size=[640, 480], ...)` 改成实际分辨率。
4. **运行**：点 CanMV IDE 左下角运行，屏幕应出现摄像头画面与 `diseased/healthy` 检测框。
5. **反馈给维护者**：把 IDE 下方串口输出（尤其是报错）、屏幕照片/截图反馈给维护者。

## 3. 可能遇到的问题

| 现象 | 原因 / 处理 |
|---|---|
| `load kmodel failed` / `kmodel version mismatch` | 板子固件与 nncase 2.11 不匹配。把 **固件版本号**（CanMV IDE 关于页或上电串口日志）反馈给维护者，我用对应 nncase 重新编译 |
| `ImportError: aidemo` 或没有 `yolov8_det_postprocess` | 固件较旧；反馈给维护者固件版本，我改成纯 Python 后处理或升级固件 |
| 画面有但无框 | 先降 `CONF_THRESHOLD` 到 0.15 试；确认摄像头画面是上海青叶片；标签顺序 `diseased, healthy` 不要反 |
| 显示比例不对/黑边 | 改 `display_size` 与 `RGB888P_SIZE`，或把 `DISPLAY_MODE` 在 lcd/hdmi 间切换 |
| 帧率低 | 这是 320 输入 + float kmodel 的正常现象；先保证能出框，再考虑量化/降分辨率 |

## 4. 上板联调需要回传的信息

1. **CanMV 固件版本**（最重要，决定 kmodel 兼容性）；
2. 板子型号/屏幕分辨率；
3. 运行后的串口日志 + 屏幕照片（有框/报错都发）。

拿到这些即可把脚本适配到对应固件 API，并在仓库中更新上板记录。
