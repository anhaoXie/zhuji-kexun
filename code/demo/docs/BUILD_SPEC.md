# 演示程序构建规范

> 本文件约定本地演示（手机端 H5 / PC 棚务台 / 微信小程序）的页面结构、演示数据口径、安全约束与视觉规范。
> 接口契约见 [`api_contract.md`](api_contract.md)，K230 图传见 [`K230_实时图传_API.md`](K230_实时图传_API.md)。

## 0. 背景与范围

演示程序用于：

1. 在无硬件时展示完整业务闭环（监控 → 控制 → 图传 → 报表）；
2. 与 K230 联调时展示实拍图传与检测框；
3. 生成高清界面截图，用于项目展示。

**不承诺**：微信小程序已上线、实车实时图传、远程控车已量产。演示口径统一为「界面与本地联调完成，车端接口按设计预留，二期接实车」。

## 1. 页面结构

### 手机端 H5（390×844）

| Tab | 内容 |
|---|---|
| 监控 | 台位进度、电量、航线、最近结果、暂停/继续 |
| 控制 | 模式切换（远程模式需确认）、摇杆、急停、安全卡 |
| 图传 | K230 实拍/演示画面、检测框、码率与延迟、开关 |
| 报表 | KPI、六状态分布、待复核列表、确认/改判、导出 CSV |

### PC 棚务台（1440×900）

| 视图 | 快捷键 | 内容 |
|---|---|---|
| 总览 | 1 | 棚区平面、机器人位置、20 个停靠位、64 株刻度、异常点 |
| 任务 | 2 | 任务卡、批次、待办 |
| 图传 | 3 | 车端相机与检测框 |
| 复核 | 4 | 待复核队列、逐株确认/改判 |
| 报表 | 5 | KPI、六状态、导出 |
| 设备 | 6 | 链路、电量、自检 |

## 2. 演示数据口径（mock）

| 项 | 取值 | 说明 |
|---|---|---|
| 棚 | 1 号棚 | 2 号棚显示「未接入」，不伪造第二棚数据 |
| 台位 | 4 床 × 4 台位 = 16 台位 | 当前进度示例：7/16 |
| 株数 | 64 株 | 4 株/台位 × 16 台位 |
| 记录 | 9 条示例记录 | 含待复核与已确认 |
| 六状态分布 | 新发/持续/加重/好转/已处理/疑似误报 | 数值为演示值 |
| KPI | 找回率、有结论率等 | **均为界面演示值，不是实测指标**；实测口径见 `docs/07-metrics.md` |
| 固件/模型版本 | 示例版本号 | 发布前按实际版本统一替换 |

> 演示数字仅用于说明界面结构与交互，不得作为项目指标引用。

## 3. 安全约束（三处一致）

H5、服务端仿真、小程序三处必须保持一致：

1. **手机端控车只在「远程模式」开放**，切换需二次确认；
2. **2.4G 遥控器优先**，软件控制不抢占；
3. **失联 500 ms 内停车**，急停硬件优先。

## 4. 接口契约

- 本地服务：`GET /api/state`、`GET /api/report`、`GET /api/export/csv`、`WS /ws` 等；
- 设备上行：`POST /api/device/frame|detection|telemetry`、`GET /api/device/commands`、`POST /api/device/ack`；
- 字段与错误码以 [`api_contract.md`](api_contract.md) 为准。

## 5. 视觉规范

| 项 | 规范 |
|---|---|
| 色彩 | 深绿导轨 + 纸张灰工作区 + 黄铜色状态点；状态色克制、不靠颜色单独表意 |
| 字体 | 中文无衬线；数字用等宽/DIN 风格 |
| 形状 | 直角面板、细线分隔；不用渐变、玻璃拟态、彩色大圆角卡片 |
| 密度 | 手机端单屏可读；PC 端按控制台密度排布 |
| 动效 | 仅保留必要的状态变化，不做装饰性动画 |

## 6. 文案规范

- 说人话：不用「赋能/一站式/智能生态」这类宣传词；
- 每个数字都标注是演示值还是实测值；
- 边界主动写：图传默认关闭、识别在车端、控车仅远程模式；
- 不承诺未验证的能力。
