# PC 端棚务台：界面说明与可用图注

日期：2026-11-04　｜　对应文件：`code/demo/web_pc/`、`code/demo/shots_pc/`

## 1. 为什么单独做 PC 端

手机端解决“在棚里看一株、控车、急停”；PC 端解决“在值班室看整棚、排任务、复核异常、导出批次报表”。两个端的场景不同，所以 PC 端没有把 390×844 的手机界面横向拉大，而是按桌面值班台重新排：

- 左侧：棚区列表、当前批次进度、待办；
- 中间：棚区平面（4 床 × 5 停靠位、机器人位置、异常点、64 株刻度）；
- 右侧：车端相机、株位档案；
- 底部：异常队列与实时事件流；
- 顶部：批次、搜索、链路、模式、时间、值班人。

## 3. 设计说明（去 AI 味）

- 主色是**墨绿 + 纸张灰 + 黄铜**；不用紫蓝渐变、不用玻璃拟态、不用彩色大圆角卡片。
- 首屏主体是**暗色棚区平面**，不是“大数字 + 渐变”的默认看板；KPI 只是平面图上方的窄条。
- 字体：中文 Microsoft YaHei UI / 思源黑体，数字 Bahnschrift（DIN 风格）+ tabular-nums；坐标与批次号用等宽字体。
- 文案只写值班语言：“第 7/20 停靠位”“B2 台 2 位叶片遮挡”“上次 10-31 / 持续 / 0.73”，不写“智能/赋能/一站式”。
- 结构线、刻度、比例尺、指北、注册角标都是信息装置，不是装饰；地图上 64 个株位刻度对应 64 株，20 个停靠位对应 20 站。
- 不伪造第二棚：2 号棚明确显示“未接入”；截图与数据口径统一为 1 号棚、批次 B-20261104-01。

## 5. 启动与截图

```powershell
# 启动服务 + 浏览器
启动PC演示.cmd
# 或
python server\app.py
# 打开
http://127.0.0.1:8765/pc/
```

- 实时演示：不接 `freeze/mock`，页面连 `/ws` 与 `/api/state`，机器人位置和事件会动。
- 固定出图：`http://127.0.0.1:8765/pc/?view=overview&freeze=1&mock=1`（其余视图把 `view=` 换成 review/report/video/tasks/device）。
- 截图：`code/demo/shots_pc/`，6 张 1440×900、2× 像素密度；`桌面端_四屏.png` 是 2×2 拼图（演示 PPT 用）。

## 6. 边界

- 演示数据来自本地仿真服务；车端相机为演示帧，K230 在线时自动切 `/api/camera/latest.jpg` 或 MJPEG。
- 任务创建/指派/自检是前端演示 toast；复核、模式切换、图传开关走真实接口。
- 页面里出现的“规则表 v2.4 / 模型 v0.8.3 / fw v1.0.0”是演示版本号，正式发布前可按实际版本统一替换。
