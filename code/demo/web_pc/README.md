# PC 棚务台 · 界面说明

日期：2026-11-04　｜　文件：`web_pc/index.html`、`web_pc/css/desk.css`、`web_pc/js/desk.js`

## 1. 它和手机端不是同一件事

| | 手机端（小程序/H5） | PC 棚务台 |
|---|---|---|
| 谁用 | 棚里操作员、巡检员 | 基地管理员、植保负责人、值班室 |
| 场景 | 走到棚边看一株、控车、急停 | 坐着看整棚、排任务、复核异常、导出批次报表 |
| 信息密度 | 单列、卡片、大按钮 | 三栏、平面图、台账、键鼠快捷键 |
| 主视觉 | 车端相机与状态卡 | 棚区平面（4 床 × 5 停靠位）+ 株位档案 |
| 关键动作 | 摇杆/云台/图传开关 | 复核、指派、导出、打印、搜索株位码 |

因此 PC 端没有把手机界面放大，而是按“值班台”重做：左侧棚区与批次、中间棚区平面、右侧车端相机与株位档案、底部异常队列与事件流。

## 2. 六个视图

1. **总览**：棚区平面（机器人位置、20 个停靠位、异常点、64 株刻度）、KPI、车端相机、株位档案、异常队列、实时事件。
2. **任务**：本班任务、范围、发起人、状态、预计时长；右侧班组与任务规则。
3. **图传**：16:9 监看、检测框、云台俯仰、最近 4 帧、本帧检测、监看记录。
4. **复核**：3 条低置信记录、缩略图、置信度、确认/改判/指派；右侧复核口径与已处理。
5. **报表**：批次 KPI、六状态条形、批次摘要、明细表、批次结论、时间线、复核人/审核/导出时间、打印与 CSV。
6. **设备**：车端遥测、安全联锁、模块状态（K230/ESP32-C3/STM32/本地服务）。

快捷键：`1—6` 切视图，`F` 打开搜索，`Esc` 关搜索/清选择；地图色点、队列表格、复核卡片都可点选联动。

## 3. 设计取舍（去 AI 味）

- **不用渐变、玻璃拟态、彩色大圆角卡片**：面板是直角、1px 细线、纸张灰工作区；深色只留给导轨和棚区平面。
- **不做“大数字 + 渐变”的默认首屏**：首屏主体是棚区平面图，KPI 只是窄条，数在图上。
- **不做营销文案**：界面里没有“智能/赋能/一站式/让……更……”，只有“第 7/20 停靠位”“3 株待复核”“上次 10-31 / 持续 / 0.73”这类值班语言。
- **不用图标字体/emoji**：导航是手写 SVG 线框，状态用色点与直角标签。
- **不做满屏卡片网格**：信息按操作顺序排（棚区 → 平面 → 相机/株位 → 异常 → 事件），密度像仪表台，不像官网。
- **字体**：中文用 Microsoft YaHei UI / 思源黑体，数字用 Bahnschrift（DIN 风格）并开 tabular-nums；时间、坐标、批次号用等宽字体。
- **颜色**：纸张灰 `#F5F4EE` + 墨绿 `#2E5A45` + 黄铜 `#A8862F` + 砖红 `#9E3A2B`。没有紫色、没有高饱和渐变；红色只给新发与急停。
- **留白与不完美**：地图右下留了 `A` 角标、比例尺、指北；事件流里保留“4G 预留链路未启用”“叶片遮挡，已生成补拍任务”这类现场话。

## 4. 演示与截图

```powershell
# 启动（服务 + 浏览器）
启动PC演示.cmd
# 或
python server\app.py
# 打开 http://127.0.0.1:8765/pc/
```

- 实时模式：连 `/ws` 与 `/api/state`，顶部显示“WS 已连接”，机器人/时间会动。
- 出图模式：`?view=overview&freeze=1&mock=1` 固定演示数据，不连 WS，适合截图/打印。
- 截图目录：`shots_pc/overview.png`、`review.png`、`report.png`、`video.png`、`tasks.png`、`device.png`（1440×900，2× 像素密度）。
- 复核、模式切换、图传开关走真实 WebSocket；导出 CSV 走 `/api/export/csv`；打印用浏览器打印样式（A4 横向）。

## 5. 边界

- 数据来自本地仿真服务；车端相机为演示帧（`assets/cam_frames/`），K230 在线时自动切 `/api/camera/latest.jpg` / MJPEG。
- “任务创建”“指派复核”“设备自检”在演示版只给 toast，不写后端；复核与模式切换是真接口。
- 2 号棚显示“未接入”，不伪造第二棚数据。
- 截图里的批次、株位码、事件与设计稿 v19 的 1 号棚 64 株 / 9 条记录口径一致；换批次需同步改 mock 与截图。
