# 13 · 选题与方向调研

> 本页记录「为什么做这个作品」以及五条候选方向的比较方法。结论先行，证据分级，避免把「潜力」当成「证据」。

## 1. 调研方法

### 1.1 证据分级

| 等级 | 定义 |
|---|---|
| **A** | 同行评审，且有真实田间/温室/现场整机或系统试验 |
| **B** | 同行评审，但仅部件、受控环境、离线数据集或小样本 |
| **C** | 预印本、会议论文、项目展示、非完整试验 |
| **D** | 厂商页面、政府新闻、媒体转述、电商页面 |

所有关键数字必须写明：**来源 + 实验条件 + 等级**。无法核实就写「未核实/存疑」，不猜测；禁止把论文指标当成本团队可达能力、把厂商宣称当独立实验。

### 1.2 评分维度

| 维度 | 问题 |
|---|---|
| 社会价值潜力 | 是否回应真实、可描述的痛点 |
| 经济价值证据 | 是否有成本/收益/节约的实测或可靠测算 |
| 生态价值证据 | 减药、减漂移、减非目标影响是否有实测 |
| 技术成熟度 | 外部证据表明别人做到了什么程度 |
| 团队匹配度 | 与团队既有的病害识别、视觉导航经历是否匹配 |
| 六个月原型可行性 | BOM、供应链、技术风险是否可控 |
| 竞赛差异化 | 能否写出「与现有技术相比的实质性特点」 |
| 证据完备度 | 现有证据能否支撑「同类研究水平」「技术指标」「市场与经济效益」 |

「潜力」与「证据」分开打分：潜力高但证据弱必须明确写。

## 2. 五条候选方向

| 方向 | 一句话 | 六个月可行性 | 结论 |
|---|---|---|---|
| **R1 小型温室巡检—识别—定位—复查** | 低速巡检 + 1—2 种明显病害 + 行/株定位 + 复查任务卡 | 4/5 | **✅ 首选** |
| **R2 绿色种植减药辅助** | 多次巡检看病害变化，给人工决策依据，不做施药执行 | 4/5 | 可嵌入 R1 |
| **R3 坡地果园辅助巡检** | 轨道式定点巡检、行/株级定位与复查闭环 | 2/5 | 谨慎 |
| **R4 绿地植物健康巡查与科普** | 单树健康档案与跨次变化，不做自主导航 | 5/5 | 就近试验 |
| **R5 识别—定位—导航—精准施药一体化** | 叶片级识别 + 3D 定位 + 靶向喷施 | 1/5 | 不建议首版 |

## 3. 为什么选 R1，并进一步收窄

### 3.1 外部证据给出的三个判断

1. **温室巡检已从「沿行采集—识别—地图」走向整机化**，但公开工作共同的问题是：只对「这一帧」负责，不区分同一株的跨次变化，也不给管理建议。
2. **按日期划分后准确度普遍下降**：随机划分下 Recall 85.2%，按日期划分约 69.8%——数据泄漏让分数虚高，换天巡检并不容易。
3. **早期无症状仍不可靠**：田间无症状株最佳检出约 59.8%，所以首版只做已显症植株是理性的。

### 3.2 收窄到「一株一档」

R1 的原始设想是「巡检 + 识别 + 定位 + 复查」。进一步调研后发现一个更根本的问题：**记录里没有「株」这个主键**，导致：

- 前后两张照片不是同一株的两个时刻，状态变化无从判断；
- 准确率只能报数据集平均分，漏了谁、误报了谁查不出来；
- 检测结果与农事动作之间缺一段衔接。

于是把方向收窄为：**先解决「回到同一株」，再谈识别与建议**——这就是「一株一档」的由来。R2（减药辅助）的价值因此变成 R1 的深化方向（六状态 + 建议），而不是另一个独立作品；R5（精准施药）因六个月不可行、且涉及药剂与合规风险，明确不做首版。

### 3.3 最终作品定义

> 面向小型温室的巡检机器人：一株一档、五级株位码、多角度拍摄、六状态判定与管理建议；先做窄口径（单一作物、少量明显病害、已显症），把可复现、可验收做扎实。

## 4. 调研过程中修正的关键判断

| 早期设想 | 调研后的修正 |
|---|---|
| 做一个「病害检测更准」的模型 | 检测模型不作为创新点主张；创新在系统层（记录、跨次、建议） |
| 直接上「识别—施药」闭环 | 首版不做施药；建议只到农事管理层面 |
| 用公开数据集指标证明能力 | 公开数据只验证链路；现场指标必须自采跨日期数据 |
| 用随机划分评估模型 | 按棚、按日期划分；公开数据也按原图分组重划，排除增强泄漏 |
| 追求全自动无人值守 | 人机协同：机器给证据与候选，人确认 |

## 5. 证据缺口（如实列出）

- 无公开的「设施巡检机器人」在售价格锚点，市场测算只能做情景分析；
- 无支付意愿调查，单位经济模型是测算不是承诺；
- 无自采的「同株跨日期」配对数据（本作品验收测试除外，原始记录随项目材料归档）；
- 跨季、跨品种泛化未验证；
- 叶背拍不到，本版不计入检出指标。

这些缺口已写入 [11 边界与合规](11-boundaries-and-compliance.md)，并在后续计划中逐项安排验证。

## 6. 对读者的启示

如果你在做类似的农业机器人项目，这篇调研给出的方法论比结论更有用：

1. **先做证据分级**，再谈方向；
2. **把「潜力」与「证据」分开**，潜力高不等于能做；
3. **用时间尺度倒推**（6 个月能做出什么），而不是先画大饼再砍；
4. **找到那个「缺了它一切都不成立」的关键对象**——本作品是「株」这个主键。
