# 11 · 边界与合规

> 主动写清边界，比夸大能力更专业。本页同时说明数据、安全与开源合规。

## 1. 技术边界

| 维度 | 当前版本 | 说明 |
|---|---|---|
| 作物 | 矮脚上海青（1 种） | 跨品种需重新采集与验证 |
| 病害 | 1—2 种外观明显的病害 | 不做全病害 |
| 棚型 | 台架式/垄作小型温室（1 类） | 露地/坡地不适用 |
| 植株状态 | 只做已显症植株 | 不做早期无症状（公开研究田间无症状株最佳检出约 59.8%） |
| 叶背 | 本版拍不到 | 结构上预留侧下视机位，本版不计入检出指标 |
| 样本 | 2 棚 × ≥50 株 × 3 日期 | 跨季、跨品种泛化需继续验证 |
| 建议 | 只到农事管理层面 | 不给药名、浓度、剂量，不替代植保员 |
| 自动化 | 人机协同 | 不承诺全自动无人值守 |

## 2. 安全边界

| 规则 | 说明 |
|---|---|
| 急停硬件优先 | 常闭安全回路，按下即断驱动 |
| 2.4G 遥控优先 | 遥控器优先级高于任何软件控制 |
| 失联 500 ms 停车 | 与上位机/遥控失联即停 |
| 远程模式闸门 | 手机端控车必须先切远程模式，只在近场使用 |
| 限速 | 底盘 ≤ 0.8 m/s；巡检 0.5 m/s；对位 0.1 m/s |
| 不带故障下地 | 开机自检不通过即报警 + 故障码 |

## 3. 数据与隐私

- **演示数据**：本地服务默认使用仿真检查点；演示画面来自团队样机或公开数据集；
- **公开数据集**：Bok Choy / PlantDoc 均为 **CC BY 4.0**，来源与修改说明见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)；
- **不含**：人脸、真实温室位置、真实农户信息、真实 Wi-Fi 凭据（代码中为 `YOUR_SSID` / `YOUR_PASSWORD` 占位）；
- **不含**：姓名、学号、院校、联系方式、身份证号等个人信息；
- **不含**：竞赛申报书、汇总表、证书、评审材料等原始文件。

## 4. 建议与责任边界

- 系统输出的是**疑似病害、置信度、六状态与候选建议**，最终由人工确认后执行；
- 建议只覆盖农事管理动作（分区、复查、通风、清残、控水控氮、送检），**不涉及农药品种、浓度与用量**；
- 系统不替代植保员，也不对最终农事决策承担责任；
- 疑似检疫性问题一律转人工与主管部门。

## 6. 脱敏声明

本仓库在公开前做了系统性脱敏处理，包括但不限于：

- 移除本地绝对路径与个人目录名；
- 移除姓名、学号、院校、学院、联系方式；
- 移除竞赛申报书、汇总表、证书、评审与答辩材料；
- 移除训练权重文件中嵌入的本地路径元数据（权重文件本身不随仓库分发）；
- 统一替换为中性工程术语（如「项目文档」「设计说明」）。

如发现仍有遗漏，请通过 Issue 联系，我们会第一时间处理。

## 7. 已知问题（如实列出）

| 问题 | 影响 | 计划 |
|---|---|---|
| 车端 STM32 / ESP32-C3 固件未开源 | 只能运行视觉端/服务端/上位机 | 整机侧维护，后续评估开源 |
| 训练权重未随仓库分发 | 公开数据基线需按脚本重训 | 提供完整训练脚本与结果曲线 |
| K230 int8 量化后置信度偏低 | 板端仅验证链路，不作精度依据 | 用自采数据微调 + 重新量化 |
| 微信小程序真机未联调 | 仅本地/开发者工具可用 | 二期补 BLE 与 HTTPS |
| 叶背拍不到 | 检出指标不含叶背 | 预留侧下视机位，后续版本 |
