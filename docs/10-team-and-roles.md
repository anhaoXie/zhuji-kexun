## 3. 协作方式

- **方案先行**：先定整机五块与数据流，再拆工；接口契约（UART / HTTP / WebSocket）先冻结再并行开发。
- **文档驱动**：每个模块交付时同步 README 与接口说明，避免口头约定。
- **指标统一口径**：检测按株统计、六状态双人盲判、找回端到端计时；所有指标指向同一组测试记录。
- **版本归档**：规则、阈值、模型版本按巡检批次归档，保证可复现。
